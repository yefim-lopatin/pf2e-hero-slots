# Героическая слот-машина

Модуль для **Foundry VTT 14.367 и Pathfinder Second Edition 8.5.0**. Дополнительные модули не нужны. Интерфейс на русском языке.

## Установка

1. На стартовом экране Foundry откройте **«Дополнительные модули» → «Установить модуль»**. В поле ссылки на манифест вставьте:

   ```text
   https://github.com/yefim-lopatin/pf2e-hero-slots/releases/latest/download/module.json
   ```

2. Нажмите **«Установить»**, откройте мир PF2e и включите **«Героическая слот-машина»** в управлении модулями.
3. Назначьте каждому игроку его основного персонажа в настройках пользователей. Тип персонажа — Character, право игрока — «Владелец». Выбранный на сцене жетон не используется.

Для ручной установки скачайте `pf2e-hero-slots.zip` из [последнего выпуска](https://github.com/yefim-lopatin/pf2e-hero-slots/releases/latest) и распакуйте в пользовательскую папку Foundry `Data/modules/`. Должен получиться путь `Data/modules/pf2e-hero-slots/module.json`, без дополнительной вложенной папки. Затем перезапустите Foundry и включите модуль в мире.

На macOS папка модулей по умолчанию: `~/Library/Application Support/FoundryVTT/Data/modules/`.

## Запуск

1. ГМ нажимает значок кубика **«Героическая слот-машина»** на левой панели. Также доступна кнопка с этим названием во вкладке настроек игры.
2. Указывает число **дополнительных перебросов** от 0 до 100. Например, 0 означает одну попытку, 2 — три попытки всего.
3. Нажимает **«Открыть всем игрокам»**. Окно появляется у всех подключённых игроков. Те, кто подключится позже, тоже увидят текущий розыгрыш, если их учётная запись уже существовала при запуске.
4. Игрок нажимает **«Испытать удачу»**, затем при наличии попыток — **«Крутить ещё»**.
5. ГМ видит использованные попытки и начисленные очки каждого игрока. Кнопка **«Завершить розыгрыш»** прекращает приём новых попыток. После этого можно начать следующий.

Если окно закрыто, его можно открыть снова через значок кубика. Закрытие окна и обновление страницы не возвращают использованные попытки. При смене назначенного персонажа или создании нового пользователя ГМ должен начать новый розыгрыш.

## Правила

- Три барабана. На каждом независимо выпадают вишня, лимон, виноград или семёрка с одинаковой вероятностью.
- Любое тройное совпадение даёт **1 героическое очко** назначенному персонажу. Шанс совпадения — **1/16 (6,25%)** на попытку.
- Победа не завершает участие. Пока остаются попытки, можно выигрывать снова.
- Максимум берётся из данных персонажа PF2e, обычно это 3. Если максимум уже достигнут, совпадение показывается, но очко не добавляется и не сохраняется на будущее. Попытка расходуется.
- Ведущий не участвует как игрок. Настройка перебросов фиксируется при запуске и одинакова для всех.
- Это самостоятельная анимация по мотивам слот-машин. Модуль не использует Telegram, его изображения или внутренний алгоритм.

## Связь и сохранение

Результат определяет подключённый ведущий ГМ. При нескольких ГМ используется ведущий, выбранный Foundry. Проверяется настоящий отправитель сообщения, переданный сервером Foundry 14; игрок не передаёт готовые результаты или количество очков.

Запросы обрабатываются по очереди. Повторное нажатие с тем же номером попытки не расходует вторую попытку. Сначала сохраняются исход и расход попытки, затем очко записывается вместе с отметкой выдачи. Если связь прервалась между этими действиями, ГМ восстанавливает сохранённый исход без новой случайной комбинации и без повторной награды.

Если ГМ отключился, окно сохраняет состояние и ждёт его возвращения. При ошибке записи ГМ видит кнопку **«Повторить сохранение результата»**. После долгого ожидания ответа стоит проверить уже показанный результат, прежде чем нажимать ещё раз.

## Проверка в игре

1. Войдите как ГМ и два разных игрока. Укажите 1 переброс и запустите розыгрыш: у обоих игроков должны открыться окна с 2 попытками.
2. Проверьте, что игроку не доступны запуск и завершение розыгрыша.
3. Используйте попытку, закройте окно и откройте снова, затем обновите страницу. Остаток должен сохраниться.
4. Быстро нажмите кнопку дважды: должна потратиться только одна попытка. После исчерпания попыток кнопка недоступна.
5. При тройном совпадении проверьте очки в листе персонажа. При достижении максимума очки больше не растут. Если попытки остались, можно крутить дальше.
6. Завершите розыгрыш с ГМ: новые попытки больше не принимаются. Новый розыгрыш выдаёт новый запас попыток.

В папке исходного проекта (не внутри установочного архива): проверка правил и сбоев сохранения — `npm test`, сборка и проверка архива — `npm run build`. Для этих команд нужен Node.js 22 или новее и утилиты zip/unzip. В самой игре они не нужны.

Для макроса типа «Скрипт» достаточно:

```js
game.modules.get("pf2e-hero-slots").api.open();
```

Программный запуск от ГМ: `await game.modules.get("pf2e-hero-slots").api.start(2)` — одна начальная попытка и два переброса. Завершение: `await game.modules.get("pf2e-hero-slots").api.end()`.
